03 · Responsive
Drei Klassen — Layout folgt Fensterbreite, nicht Gerätetyp
Compact
0 – 599 px
Navigation: Bottom-Nav (5 Tabs)
Layout: 1 Spalte
Screen-Padding 16px · Sheets von unten · FAB nie (Aktionen neben Guthaben)
Medium
600 – 1023 px
Navigation: Sidebar 92–170px
Layout: 2 Spalten (Liste + Detail)
Screen-Padding 24px · Modals zentriert · Detail ersetzt nie den Kontext
Expanded
1024 px +
Navigation: Sidebar 170px + ⌘K
Layout: 3 Spalten
Min-Fenster 960×600 · darunter Medium-Layout · Panels behalten max. Lesebreite
Übergangsregeln
Bottom-Nav ↔ Sidebar wechselt bei 600px · Split-View (Liste+Detail) ab 600px, dritte Spalte ab 1024px · Auf Desktop ist die Fenstergröße die einzige Wahrheit — ein schmales macOS-Fenster bekommt das Tablet-Layout · Touch-Targets bleiben überall ≥44px, auch auf Desktop (Convertibles).
04 · Plattform-Spezifika
iOS · Android · Windows · macOS · Linux
iOS
· Safe Areas: Bottom-Nav über Home-Indicator, Banner unter Dynamic Island
· Face ID vor jedem Send > Limit + App-Start
· System-Share-Sheet für Receive-QR/Adresse
· Haptik: success = notificationSuccess, slide-to-send = impactMedium
· Kein Android-Back — Zurück nur via ‹ oder Swipe
Android
· Adaptive Icon: fg = @+Cursor, bg = Ink #0B0D10 (Maske rund/squircle)
· System-Back schließt Sheets zuerst, verlässt nie den Send-Flow ohne Dialog
· Material You NICHT übernehmen — Pecu-Farben sind fix
· Biometric Prompt API vor Send/Seed-Reveal
· Predictive Back ab API 34 unterstützen
Windows
· Eigene Titelbar: Titel links, Minimize/Maximize/Close rechts (kein macOS-Ampel-Design)
· Acryl/Mica NICHT verwenden — Flat Ink-Hintergrund
· Tray-Icon: @ monochrom, Kontextmenü: Open / Lock / Quit
· .ico mit 16/24/32/48/256px
macOS
· Traffic Lights links, Inhalt beginnt rechts davon (52px)
· Menübar-Menü mit Standard-Rollen (App/Edit/Window/Help)
· ⌘, öffnet Settings (Konvention)
· Vibrancy NICHT verwenden
Linux
· CSD-Header wie Windows-Variante, Close rechts (GNOME) — Buttons folgen Desktop-Konvention
· SVG-Icon (skalierbar) + 512px PNG für .desktop
· Fractional Scaling testen: Hairlines auf 1.25×/1.5× (device-pixel-snap)
Desktop-Shortcuts (alle drei OS, ⌘ = Ctrl auf Win/Linux)
